# EDA Results Explanation

This document explains all the CSV files and plots generated by the GC10-DET Exploratory Data Analysis (EDA) script (`eda_gc10_det.py`).

---

## Dataset Overview

- **Source**: GC10-DET dataset from Kaggle (metal surface defect detection)
- **Images**: 2,294 grayscale images, all 2048×1000 pixels
- **Annotations**: 3,563 bounding boxes across 10 defect classes in YOLO format
- **Splits**: No predefined train/val/test split (all "unspecified")

**Use for**: Feature selection, understanding data biases.

## How to Use These Results

### For Model Training
1. **Normalization**: Use `gray_mean=85.7`, `gray_std=25.1` from `image_descriptive_statistics.csv`
2. **Class weights**: Inverse frequency from `class_distribution.csv`
3. **Anchor boxes**: Cluster `width_pixels` × `height_pixels` from `bounding_box_descriptive_statistics.csv`
4. **Loss function**: Focal loss recommended due to imbalance
5. **Augmentation**: Mosaic/MixUp critical for small classes (inclusion, punching_hole)

### For Data Split
- Current: No splits (all "unspecified")
- Run `Images_preprocessing.py` to create stratified 70/15/15 split
- Verify split balance using `split_statistics.csv` on each split

### For Quality Control
- `annotation_errors.csv` empty → annotations clean
- `images_without_valid_objects` = 2 → handle as negative samples
- No duplicates → no deduplication needed
